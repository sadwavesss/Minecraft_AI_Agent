# Подробный разбор архитектуры и кода ИИ-ассистента для игр

Этот документ представляет собой исчерпывающее описание архитектуры проекта, его модулей, классов и абсолютно каждой функции/метода.

---

## 1. Глобальная архитектура

Проект `Game Multimodal Assistant` состоит из двух основных процессов, работающих параллельно:
1.  **FastAPI Backend (Ядро)**: Отвечает за логику, работу с нейросетями (Gemini, Whisper, Silero TTS), памятью (ChromaDB), захватом экрана, прослушиванием микрофона и клавиатуры (PTT).
2.  **PySide6 Overlay (Пользовательский интерфейс)**: Прозрачное окно поверх всех остальных окон, которое отображает статус, субтитры и предоставляет меню настроек. Общается с ядром через HTTP-запросы (Polling).

---

## 2. Разбор по файлам и функциями

### `backend/main.py`
Точка входа в приложение. Инициализирует FastAPI и запускает Оверлей.
-   **`launch_overlay_process()`**: Использует `subprocess.Popen` для запуска `backend.overlay.window` как независимого процесса.
-   **`lifespan(app: FastAPI)`**: Асинхронный контекстный менеджер. При старте сервера запускает Оверлей, инициализирует `container.start_all()` и `hotkey_service.start()`. При выключении корректно останавливает все сервисы и убивает процесс Оверлея.
-   **`app`**: Экземпляр FastAPI с подключенным CORS и роутером `/api`.
-   **Настройка Uvicorn**: В блоке `if __name__ == "__main__":` настраивается фильтрация логов через `EndpointFilter`, чтобы спам от постоянного опроса Оверлеем (polling) не засорял терминал.

### `backend/core/container.py`
Реализует IoC-контейнер (Inversion of Control), хранящий состояния и управляющий жизненным циклом.
-   **`ApplicationContainer` (Класс)**:
    -   **`__init__(self)`**: Создает экземпляры `ScreenCapture`, `VoiceListener`, `MemoryService`, `LLMService`, `TTSManager`, `RequestPipeline`. Хранит настройки (персона, голос, громкость, видимость элементов). Подписывается на колбэки транскрибации голоса.
    -   **`_get_pipeline_settings(self) -> dict`**: Возвращает текущие настройки голоса и персоны для конвейера.
    -   **`_on_pipeline_response(self, text: str)`**: Колбэк, вызываемый конвейером при получении ответа от Gemini. Сохраняет текст для выдачи Оверлею.
    -   **`_is_cancel_command(self, text: str) -> bool`**: Анализирует текст с микрофона. Если фраза короткая (до 3 слов) и содержит стоп-слово (например, "заткнись", "стоп"), возвращает `True`.
    -   **`_on_voice_transcription(self, text: str)`**: Обработчик успешного распознавания голоса. Если это команда отмены — прерывает TTS и очищает очередь. Если это обычный запрос — делает скриншот и отправляет задачу (голос + картинка) в `pipeline.add_request`.
    -   **`set_overlay_status(self, status: str)`**: Обновляет статус для Оверлея (например, "Recording...").
    -   **`start_all(self)` / `stop_all(self)`**: Запускает и останавливает потоки захвата экрана, голоса и конвейера.
-   **`container`**: Глобальный синглтон этого класса.

### `backend/services/pipeline.py`
Асинхронный конвейер задач. Гарантирует, что запросы обрабатываются по очереди (FIFO).
-   **`UserRequest` (Dataclass)**: Структура данных для хранения текста, скриншота и времени запроса.
-   **`RequestPipeline` (Класс)**:
    -   **`__init__(...)`**: Принимает зависимости и колбэки. Создает `asyncio.Queue`.
    -   **`start(self)` / `stop(self)`**: Запускает/останавливает фоновую задачу `_worker`.
    -   **`add_request(self, text, image_bytes, frames_buffer)`**: Добавляет запрос в очередь.
    -   **`clear_queue(self)`**: Очищает очередь запросов (используется при команде отмены).
    -   **`_worker(self)`**: Бесконечный цикл, который берет задачу из очереди, запрашивает историю из `MemoryService`, подготавливает настройки TTS, отправляет запрос в `LLMService` (Gemini), сохраняет ответ в историю и параллельно запускает вывод текста в Оверлей и звук в `TTSManager`.

### `backend/services/llm_service.py`
Сервис интеграции с Google Gemini.
-   **`LLMService` (Класс)**:
    -   **`__init__(self)`**: Настраивает `genai` используя ключ из `settings`.
    -   **`ask_gemini(self, question, image_bytes, history, system_prompt) -> str`**: Формирует запрос. Берет системный промпт (жесткие правила поведения + выбранная персона), прикрепляет историю диалога, текущий скриншот (если есть) и текст. Отправляет в модель `gemini-flash-lite-latest` и возвращает текст ответа.

### `backend/services/tts_service.py`
Сервис генерации речи на базе локальной модели Silero TTS.
-   **`TTSManager` (Класс)**:
    -   **`__init__(...)`**: Инициализирует очередь `Queue` и запускает фоновый поток воспроизведения `_worker`.
    -   **`set_speaker(self, speaker_name)`**: Меняет голос.
    -   **`set_volume(self, volume)`**: Меняет громкость.
    -   **`stop_playback(self)`**: Останавливает воспроизведение (`sounddevice.stop()`) и очищает очередь фраз.
    -   **`_init_model(self)`**: Загружает PyTorch модель `silero_tts` из сети/кэша и отправляет на GPU/CPU.
    -   **`say(self, text)`**: Кладет текст в очередь.
    -   **`_worker(self)`**: Забирает текст из очереди, оборачивает в SSML-теги (для ускорения речи без питча через `<prosody rate="...">`), генерирует аудио-тензор, нормализует громкость и воспроизводит через `sounddevice`.

### `backend/services/memory_service.py`
Система долговременной памяти (векторная база данных ChromaDB).
-   **`MemoryService` (Класс)**:
    -   **`__init__(self)`**: Инициализирует подключение к локальной базе `ChromaDB`.
    -   **`_init_memory(self)`**: Загружает локальную модель эмбеддингов `all-MiniLM-L6-v2`. Очищает старую память при каждом запуске программы.
    -   **`add_message(self, role, content)`**: Сохраняет сообщение (как пользователя, так и ассистента) в базу с меткой времени. Предварительно вызывает `_truncate_if_needed()`.
    -   **`get_context(self, query, n_results)`**: Семантический поиск по истории (RAG).
    -   **`get_recent_history(self, limit)`**: Извлекает хронологически последние `limit` сообщений.
    -   **`clear_session(self)`**: Очищает коллекцию.
    -   **`_truncate_if_needed(self)`**: Если количество записей превысило лимит (100), удаляет самые старые записи (Truncation), чтобы база не раздувалась.

### `backend/services/hotkey_service.py`
Слушает глобальные нажатия клавиш клавиатуры.
-   **`HotkeyService` (Класс)**:
    -   **`__init__(self)`**: Настраивает слушатель `pynput` на нажатие F2 и левого Ctrl.
    -   **`_on_press(self, key)`**: Если нажато F2, переключает видимость Оверлея. Если нажат Ctrl (и ранее не был нажат) — вызывает `voice_listener.start_recording()` и меняет статус на `Recording...`.
    -   **`_on_release(self, key)`**: Если отпущен Ctrl — вызывает `voice_listener.stop_recording()` и меняет статус на `Processing...`.
    -   **`start(self)` / `stop(self)`**: Запуск и остановка слушателя клавиатуры.
-   **`hotkey_service`**: Синглтон сервиса.

### `backend/core/capture.py`
Отвечает за постоянный фоновый захват экрана.
-   **`ScreenCapture` (Класс)**:
    -   **`__init__(...)`**: Пытается инициализировать быстрый `dxcam`, при неудаче готовит фоллбэк `mss`. Создает цикличный буфер кадров.
    -   **`start(self)` / `stop(self)`**: Управляет потоком захвата.
    -   **`_run(self)`**: Бесконечный цикл в отдельном потоке. Делает скриншоты с заданной частотой кадров (по умолчанию 12-15 fps). Сохраняет последний кадр и раз в секунду записывает кадр в `frame_buffer`.
    -   **`get_frame(self)` / `get_frame_buffer(self)`**: Безопасный (через Lock) доступ к последнему скриншоту или массиву истории скриншотов.

### `backend/core/vision.py`
Утилиты обработки изображений.
-   **`preprocess_frame(frame, width, height, quality)`**: Сжимает OpenCV-кадр (numpy array) до 720p и конвертирует в JPEG-байты. Уменьшает нагрузку при отправке в API Gemini.

### `backend/core/voice.py`
Отвечает за транскрибацию голоса в текст.
-   **`VoiceListener` (Класс)**:
    -   **`__init__(...)`**: Настраивает микрофон. Вызывает загрузку модели `faster-whisper`.
    -   **`_init_model(self)`**: Загружает модель (по умолчанию "base") с `int8` квантованием для работы на CPU.
    -   **`start(self)`**: Открывает поток `pyaudio` и запускает поток чтения.
    -   **`start_recording(self)` / `stop_recording(self)`**: Управляет флагами записи. При остановке передает аудио на распознавание.
    -   **`_read_loop(self)`**: Фоновый поток, читающий байты с микрофона и сохраняющий их в массив, если активен флаг записи.
    -   **`_process_audio(self, audio_np)`**: Отправляет массив аудио в `faster-whisper`. Вызывает колбэк `on_transcription` с распознанным текстом.
    -   **`stop(self)`**: Закрывает поток `pyaudio`.

### `backend/api/routes.py`
Определяет эндпоинты FastAPI.
-   **`SettingsUpdate` (Pydantic BaseModel)**: Схема для POST-запросов настроек.
-   **`health()`**: Возвращает `{"status": "ok"}`.
-   **`get_latest_response()`**: Возвращает последний текст для субтитров из `container.current_overlay_text`.
-   **`get_status()`**: Возвращает текущий статус (IDLE, Recording...), видимость окон и настроек для Оверлея.
-   **`get_settings_meta()` / `get_settings()` / `update_settings(settings)`**: Получение списка доступных голосов/персон, чтение текущих настроек и их обновление в `container`.
-   **`start_all()` / `stop_all()`**: Управление полным жизненным циклом (запуск/остановка записи и захвата).
-   **`ask(question, include_frame)`**: Ручной тестовый эндпоинт для имитации запроса. Берет скриншот и закидывает в `pipeline`.

### `backend/core/config.py`
Загрузка конфигурации из `.env` файла с помощью `pydantic_settings`.
-   **`EndpointFilter`**: Класс-фильтр для модуля `logging`, убирающий спам от роутов `/api/latest_response` и `/api/status`.
-   **`Settings`**: Модель с ключами для Gemini, настройками модели Whisper и параметрами TTS.
-   **`get_settings()`**: Кешируемая функция для получения настроек.

### `backend/core/presets.py`
Работа с JSON-файлами пресетов (характеры и доступные голоса).
-   **`load_presets()`**: Читает `data/presets.json`. Возвращает словарь персон (ключ-название, значение-промпт) и список голосов.
-   **`save_presets(personas, voices)`**: Перезаписывает JSON-файл.

### `backend/overlay/window.py`
Главный класс графического интерфейса (Оверлея).
-   **`OverlayWindow` (Класс наследующий `QtWidgets.QWidget`)**:
    -   **`__init__(self)`**: Делает окно полноэкранным, безрамочным, полупрозрачным (`WA_TranslucentBackground`). Инициализирует UI-компоненты. Запускает таймер поллинга.
    -   **`paintEvent(self, event)`**: Рисует полупрозрачную черную подложку, если активен режим настроек (интерактивный), иначе оставляет фон полностью прозрачным.
    -   **`_setup_ui(self)`**: Размещает на экране панели: `SettingsPanel`, `StatusPanel`, `HotkeyPanel`, `SubtitlesHUD`, `VisualizerHUD`.
    -   **`_on_start_clicked(self)` / `_on_stop_clicked(self)`**: Отправляют POST-запросы к бэкенду для запуска/остановки системы.
    -   **`_load_settings_once(self)`**: При первом удачном коннекте к бэкенду скачивает списки голосов и персон, инициализируя ими меню настроек.
    -   **`_on_settings_changed(self)`**: Собирает данные из UI (громкость, чекбоксы, комбобоксы) и отправляет POST-запрос с новыми настройками на бэкенд.
    -   **`_set_mode(self, interactive: bool)`**: Переключает Оверлей между режимом "Игры" (события мыши пробрасываются сквозь окно, скрыто меню) и "Меню" (видно настройки, можно кликать мышкой).
    -   **`_poll_backend(self)`**: Вызывается каждые 500мс по таймеру. Делает GET запросы к `/api/latest_response` и `/api/status`. При изменении данных эмитит сигналы PyQt, которые обновляют текст и статус в HUD-элементах.
-   **`run()`**: Точка входа в процесс Оверлея, запускает цикл `app.exec()`.

### `backend/overlay/style.py`
Файл содержит строковые константы с CSS-стилями (QSS) для PySide6/PyQt6. Включает стили для кнопок, чекбоксов, комбобоксов, ползунков и эффекта "Glassmorphism".

### `backend/overlay/components/base.py`
-   **`GlassWidget`**: Базовый фрейм с полупрозрачным фоном и закругленными краями.
-   **`DraggableGlassWidget`**: Наследует `GlassWidget`, добавляя обработчики `mousePressEvent`, `mouseMoveEvent` и `mouseReleaseEvent`, что позволяет пользователю перетаскивать HUD-элементы мышкой.

### `backend/overlay/components/hotkey_panel.py`
-   **`HotkeyPanel`**: Отрисовывает подсказки по горячим клавишам внизу экрана (Ctrl, F2).

### `backend/overlay/components/hud_subtitles.py`
-   **`SubtitlesHUD` (Наследует `DraggableGlassWidget`)**:
    -   Имеет чекбокс для скрытия субтитров и текстовое поле `response_label`.
    -   **`set_text(self, text)`**: Обновляет текст субтитров и подстраивает размер фрейма.
    -   **`toggle_interactive(self, interactive)`**: Показывает/скрывает чекбокс в зависимости от режима.

### `backend/overlay/components/hud_visualizer.py`
-   **`VisualizerHUD` (Наследует `DraggableGlassWidget`)**:
    -   Отвечает за показ статуса (IDLE, RECORDING, PROCESSING).
    -   **`set_status(self, status)`**: Меняет текст и цвет надписи в зависимости от статуса (Красный для записи, Желтый для обработки, Зеленый для ожидания).
    -   **`toggle_interactive(self, interactive)`**: Аналогично переключает элементы интерфейса.

### `backend/overlay/components/settings_panel.py`
-   **`SettingsPanel`**: Блок слева сверху.
    -   Включает выпадающие списки `combo_persona` и `combo_voice`, а также ползунок `slider_volume`.
    -   **`update_data(self, ...)`**: Безопасно (с блокировкой сигналов) заполняет списки при первой загрузке из API.

### `backend/overlay/components/status_panel.py`
-   **`StatusPanel`**: Блок по центру.
    -   Включает кнопки `start_button` и `stop_button`.
    -   **`set_active(self)`**: Меняет внешний вид кнопок, когда система запущена.
    -   **`set_offline(self)`**: Возвращает кнопки в исходное состояние при остановке.
