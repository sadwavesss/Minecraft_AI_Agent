## 🎨 Основные страницы

### 1. **Dashboard** (Дашборд)
Главная страница с обзором состояния игры.

**Компоненты:**
- Real-time статистика (события, убийства, смерти)
- Активный челлендж с прогресс-баром
- Timeline последних событий
- Статус подключения AI

**Технология:**
- WebSocket для live-updates
- Автоматический refresh каждые 3 секунды
- Цветовая индикация статуса

### 2. **Live Logs** (Живые логи)
Потоковая передача логов в реальном времени.

**Возможности:**
- WebSocket подключение для live-streaming
- Фильтрация по уровню (INFO, WARNING, ERROR)
- Кнопка auto-scroll для паузы
- Очистка логов
- Цветовая кодировка типов событий

### 3. **Challenges** (Челленджи)
Система управления игровыми вызовами.

**Функции:**
- Создание новых челленджей (kill или collect)
- Отслеживание прогресса
- Получение награды
- История выполненных челленджей
- Отмена активного челленджа

### 4. **Inventory** (Инвентарь)
Просмотр экипировки и предметов игрока.

**Отображение:**
- Главный инвентарь (сетка предметов)
- Надетая броня (шлем, нагрудник, штаны, сапоги)
- Hotbar (9 быстрых слотов)
- Offhand слот
- Локализованные названия предметов

### 5. **Crafting** (Крафты)
Браузер рецептов крафтинга с поиском.

**Возможности:**
- 115+ рецептов Minecraft
- Поиск по названию или ID
- Фильтрация по категориям
- Детали рецепта с сеткой 3x3
- Emoji для быстрой идентификации

**Категории:**
- 🔨 Tools (инструменты)
- ⚔️ Weapons (оружие)
- 🛡️ Armor (броня)
- 🧱 Blocks (блоки)
- 🎨 Decoration (декор)
- ⚡ Redstone (редстоун)

### 6. **Chat AI** (Чат с AI)
Интерактивное общение с AI агентом.

**Поддерживаемые команды:**
```
give me [item]              → Запросить предмет
summon [mob]               → Призвать существо
create challenge [desc]    → Создать челлендж
claim reward               → Получить награду
```

**Возможности:**
- Real-time сообщения
- История переписки в sidebar
- Tool-based действия
- Примеры команд

### 7. **Analytics** (Аналитика)
Анализ сессии и тактический отчет.

**Включает:**
- Количество смертей и обстоятельства
- Timeline кризисов здоровья
- Статистику боевых столкновений
- LLM-powered insights
- Красиво оформленный markdown отчет

## 🔌 API Endpoints

Фронтенд использует следующие API:

| Endpoint | Метод | Назначение |
|----------|-------|-----------|
| `/api/logs/` | GET | Получить логи |
| `/api/logs/ws` | WS | Real-time логи |
| `/api/player-state/` | GET | Статистика игрока |
| `/api/player-state/inventory` | GET | Инвентарь |
| `/api/player-state/kills` | GET | Убийства |
| `/api/challenges/` | GET/POST | Челленджи |
| `/api/challenges/{id}/claim` | POST | Получить награду |
| `/api/challenges/{id}/cancel` | POST | Отменить челлендж |
| `/api/rp/chat` | POST | Chat с AI |
| `/api/analytics/session_summary` | GET | Аналитика |
| `/api/recipes` | GET | База рецептов |

## 🐛 Troubleshooting

### Дашборд не загружается
1. Проверьте сервер запущен на http://localhost:8000
2. Очистите кэш браузера
3. Проверьте консоль браузера на ошибки

### WebSocket не подключается
1. Убедитесь сервер запущен
2. Проверьте настройки firewall
3. Проверьте нет ли прокси

### Логи не обновляются
1. Запустите игру
2. Проверьте endpoint `/api/logs/` работает
3. Проверьте WebSocket подключение
4. Обновите страницу

### Крафты не загружаются
1. Проверьте `/api/recipes` endpoint
2. Проверьте консоль на ошибки
3. Проверьте JSON файл в data/ папке
