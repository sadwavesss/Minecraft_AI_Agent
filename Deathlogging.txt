Чтобы логировать именно киллы игрока в Fabric‑моде под 1.20.1, нужно отлавливать момент, когда какой‑то игрок “приносит смерть” другому живому существу (в том числе игроку) и записывать это в лог‑файл или в консоль.

Ниже — простой, понятный Copilot‑ориентированный пример: как сделать систему логирования киллов игрока в Fabric‑моде на 1.20.1.

1. Что нужно поставить
Fabric Loader + Fabric API 1.20.1 (обязательно, чтобы использовать ServerLivingEntityEvents.AFTER_DEATH).

В твоём build.gradle должна быть зависимость на fabric-api (генерируется обычно через loom).

2. Основная идея работы
Мы будем ловить событие ServerLivingEntityEvents.AFTER_DEATH — оно срабатывает, когда сущность (моб или игрок) умирает на сервере.

Внутри обработчика смотрим, кто нанёс смертельный удар (DamageSource), и если атакующий — PlayerEntity, записываем килл в лог.

3. Пример Java‑кода (для мода)
Создай Java‑класс, например KillLogger.java:

java
package your.mod.id;

import net.fabricmc.fabric.api.entity.event.v1.ServerLivingEntityEvents;
import net.minecraft.entity.Entity;
import net.minecraft.entity.LivingEntity;
import net.minecraft.entity.damage.DamageSource;
import net.minecraft.entity.player.PlayerEntity;
import net.minecraft.server.network.ServerPlayerEntity;
import net.minecraft.text.Text;
import net.minecraft.util.Formatting;

public class KillLogger {

    public static void init() {
        // Ловим момент, когда сущность умерла
        ServerLivingEntityEvents.AFTER_DEATH.register((livingEntity, damageSource) -> {
            logKill(livingEntity, damageSource);
        });
    }

    private static void logKill(LivingEntity victim, DamageSource source) {
        Entity attacker = source.getAttacker();
        if (attacker instanceof PlayerEntity player) {
            String playerName = player.getName().getString();
            String victimName = victim.getName().getString();

            // Выводим в консоль сервера
            System.out.printf("[KillLog] %s killed %s with %s\n",
                    playerName, victimName, source.getName());

            // Либо можешь отправить игроку сообщение в чат
            // if (player instanceof ServerPlayerEntity) {
            //     ((ServerPlayerEntity) player).sendMessage(
            //         Text.literal("You killed " + victimName)
            //             .formatted(Formatting.GREEN)
            //     );
            // }
        }
    }
}
Этот код:

Регистрирует слушатель на AFTER_DEATH.

Проверяет, есть ли у DamageSource атакующий игрок (source.getAttacker()).

Если да — пишет строку вида [KillLog] Alice killed Zombie with player в лог сервера / консоль.

4. Как подключить в твой мод
В главном классе мода (где @Mod или ModInitializer):

java
package your.mod.id;

import net.fabricmc.api.ModInitializer;

public class YourMod implements ModInitializer {
    @Override
    public void onInitialize() {
        KillLogger.init();
    }
}
