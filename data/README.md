## 🔨 minecraft_crafting_recipes.json

Полная база рецептов крафтинга Minecraft с сеткой 3x3.

### Формат рецепта

```json
{
  "железная_кирка": {
    "name": "Железная кирка",
    "description": "Мощный инструмент для добычи каменных материалов",
    "category": "tools",
    "grid": [
      ["железный_слиток", "железный_слиток", "железный_слиток"],
      ["палка", "палка", null],
      [null, null, null]
    ]
  }
}
```

### Поля рецепта

| Поле | Тип | Описание |
|------|-----|---------|
| `name` | string | Локализованное название (Русский) |
| `description` | string | Описание и применение |
| `category` | string | Категория: tools, weapons, armor, blocks, decoration, redstone |
| `grid` | array[3][3] | Сетка крафтинга 3x3 |

### Категории

- **tools** - Инструменты (кирки, топоры, лопаты, мотыги, верстак, печь)
- **weapons** - Оружие (мечи, луки, стрелы, щиты)
- **armor** - Броня (шлемы, нагрудники, штаны, сапоги)
- **blocks** - Блоки (кирпичи, песок, булыжник, плиты, стекло, двери)
- **decoration** - Декорации (факелы, кровати, сундуки, заборы, люки)
- **redstone** - Редстоун (поршни, диспенсеры, воронки, повторители)

## 📜 logs.json

История всех игровых событий и действий.

### Формат события

```json
{
  "timestamp": "2026-05-06T18:00:00.000Z",
  "event_type": "kill",
  "entity": "creeper",
  "details": {
    "player_health": 20,
    "coordinates": [100, 64, 200]
  },
  "level": "INFO"
}
```

### Типы событий

- **startup** - Запуск игры
- **shutdown** - Закрытие игры
- **kill** - Убийство существа
- **death** - Смерть игрока
- **inventory_change** - Изменение инвентаря
- **low_health** - Критическое здоровье
- **near_hostile** - Враг рядом
- **item_craft** - Крафт предмета
- **item_break** - Поломка предмета

## 🔄 Синхронизация данных

### Как работает загрузка рецептов

1. Backend загружает JSON из `data/minecraft_crafting_recipes.json`
2. Frontend запрашивает `/api/recipes` endpoint
3. Данные кешируются в localStorage браузера
4. При поиске используется локальная база для скорости

### Обновление базы

Чтобы добавить новый рецепт:

1. Отредактируйте `minecraft_crafting_recipes.json`
2. Добавьте объект рецепта с правильным форматом
3. Перезагрузите сервер или очистите кэш браузера
4. Проверьте в UI

## 🔍 Поиск и фильтрация

### Поддерживаемые фильтры

- **По названию** - Полнотекстовый поиск
- **По ID** - Точный ID предмета
- **По категории** - Фильтрация по типу
- **По ингредиентам** - Поиск рецептов содержащих материал

## 🐛 Troubleshooting

### Рецепты не загружаются
1. Проверьте что `minecraft_crafting_recipes.json` существует
2. Проверьте валидность JSON (`npm run validate-json`)
3. Проверьте консоль на синтаксические ошибки

### Невалидные ингредиенты в сетке
1. Убедитесь что ID совпадают с `minecraft_items.json`
2. Проверьте grid массив - ровно 3x3
3. `null` для пустых ячеек

### Поиск не работает
1. Проверьте индекс поиска обновлен
2. Очистите localStorage браузера
3. Перезагрузите страницу
