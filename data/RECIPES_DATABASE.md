# Minecraft Crafting Recipes Database

## Описание

JSON-база данных всех крафтов для приложения Minecraft AI Assistant.

## Файл

```
data/minecraft_crafting_recipes.json
```

## Структура

### Основной формат

```json
{
  "recipes": {
    "recipe_key": {
      "name": "Название на русском",
      "description": "Описание предмета и его применение",
      "grid": [
        ["ингредиент", "ингредиент", "пусто"],
        ["ингредиент", "пусто", "пусто"],
        ["пусто", "пусто", "пусто"]
      ]
    }
  }
}
```

### Поля рецепта

| Поле | Тип | Описание |
|------|-----|---------|
| `name` | string | Русское название предмета |
| `description` | string | Короткое описание и применение (1 строка) |
| `grid` | array[3][3] | Сетка крафтинга (массив 3x3 строк) |

### Сетка крафтинга

- Массив из **ровно 3 строк**
- Каждая строка содержит **ровно 3 элемента**
- Каждый элемент - **строка (string)**
- Пустые ячейки должны быть **"пусто"**
- Ингредиенты должны быть на **русском языке**

Пример валидной сетки:
```json
[
  ["доска", "доска", "доска"],
  ["доска", "пусто", "доска"],
  ["доска", "доска", "доска"]
]
```

## Как добавить новый рецепт

1. Откройте `data/minecraft_crafting_recipes.json`
2. Добавьте новый рецепт в секцию `"recipes"`:

```json
"новый_предмет": {
  "name": "Название на русском",
  "description": "Описание применения",
  "grid": [
    ["инградиент1", "инградиент2", "пусто"],
    ["инградиент3", "пусто", "пусто"],
    ["пусто", "пусто", "пусто"]
  ]
}
```

3. Проверьте валидность JSON (не должно быть синтаксических ошибок)
4. Запустите тест:
```bash
python test_recipes.py
```

## Правила для рецептов

1. **Ключ рецепта** (recipe_key):
   - Строчные буквы (lowercase)
   - Без пробелов (используйте подчёркивание или дефис)
   - Уникален в базе
   - Предпочтительно совпадает с инфинитивной формой в русском

2. **Название** (name):
   - Русский язык
   - Основное именование предмета
   - Может отличаться от ключа

3. **Описание** (description):
   - Одна строка
   - Русский язык
   - Указывает на применение

4. **Сетка** (grid):
   - Ровно 3x3
   - Все элементы - строки
   - Пустые ячейки - "пусто"
   - Ингредиенты на русском

## Интеграция с кодом

### Загрузка рецептов

```python
from api.minecraft_recipes import get_all_recipes

recipes = get_all_recipes()
# recipes = {"палка": {...}, "печь": {...}, ...}
```

### Поиск рецепта

```python
from api.minecraft_recipes import search_recipe

recipe = search_recipe("железный меч")
# recipe = {"name": "Железный меч", "description": "...", "grid": [...]}
```

### Валидация

```python
from api.minecraft_recipes import validate_all_recipes

result = validate_all_recipes()
print(f"Valid: {len(result['valid'])}")
print(f"Invalid: {len(result['invalid'])}")
```
