title Сценарий 3: Мониторинг и настройка системы

actor "Администратор\n(браузер)" as Админ
participant "Веб-панель\n(index.html)" as ПанельЛоги
participant "Веб-панель\n(responses.html)" as ПанельОтветы
participant "Веб-панель\n(settings.html)" as ПанельНастройки
participant "Сервер FastAPI\n(logs.py)" as СерверЛоги
participant "Сервер FastAPI\n(advice.py)" as СерверЛЛМ
participant "Сервер FastAPI\n(settings.py)" as СерверНастройки
participant "Буфер событий\n(logs_db)" as Буфер

== Поток 1: Мониторинг событий в реальном времени ==

Админ -> ПанельЛоги : Открыть /admin
ПанельЛоги -> СерверЛоги : GET /api/logs/?limit=100\n(начальная загрузка)
СерверЛоги -> Буфер : Получить последние\n100 событий
Буфер --> СерверЛоги : [LogEntry × N]
СерверЛоги --> ПанельЛоги : JSON-массив событий
ПанельЛоги -> Админ : Таблица событий\nс цветовой маркировкой

ПанельЛоги -> СерверЛоги : WebSocket\nws://.../api/logs/ws\n(установить соединение)
СерверЛоги --> ПанельЛоги : Соединение установлено

loop Новые события от мода
    СерверЛоги -> ПанельЛоги : WebSocket-сообщение\n{LogEntry}
    ПанельЛоги -> Админ : Добавить строку\nв таблицу без перезагрузки
end

== Поток 2: Просмотр истории ответов ИИ ==

Админ -> ПанельОтветы : Открыть /admin/responses
ПанельОтветы -> СерверЛЛМ : GET /api/rp/history?limit=100
СерверЛЛМ --> ПанельОтветы : [{response, source,\nlevel, confidence,\ntimestamp} × N]
ПанельОтветы -> Админ : Лента ответов ассистента

ПанельОтветы -> СерверЛЛМ : WebSocket\nws://.../api/rp/ws\n(установить соединение)

loop Новые ответы ассистента
    СерверЛЛМ -> ПанельОтветы : WebSocket-сообщение\n{ответ ассистента}
    ПанельОтветы -> Админ : Добавить запись в ленту
end

== Поток 3: Изменение настроек системы ==

Админ -> ПанельНастройки : Открыть /admin/settings
ПанельНастройки -> СерверНастройки : GET /api/settings/
СерверНастройки --> ПанельНастройки : {analysis_interval,\nthreat_threshold,\nenable_voice,\nmax_threats_display}
ПанельНастройки -> Админ : Форма с текущими значениями

Админ -> ПанельНастройки : Изменить параметры\nи нажать «Сохранить»
ПанельНастройки -> СерверНастройки : PUT /api/settings/\n{новые значения}
СерверНастройки -> СерверНастройки : Валидация через Pydantic\nСохранить в settings.json
СерверНастройки --> ПанельНастройки : {обновлённые настройки}
ПанельНастройки -> Админ : Подтверждение сохранения

== Поток 4: Переключение модели LLM ==

Админ -> ПанельНастройки : Выбрать модель\nиз выпадающего списка\n(llama / qwen / qwen3-local)
ПанельНастройки -> СерверЛЛМ : GET /api/rp/models/available
СерверЛЛМ --> ПанельНастройки : {current_model,\navailable_models,\nmodel_details}

Админ -> ПанельНастройки : Подтвердить выбор
ПанельНастройки -> СерверЛЛМ : POST /api/rp/models/switch\n?model_type=qwen
СерверЛЛМ -> СерверЛЛМ : Обновить llm_config\nПересоздать GroqClient\nСохранить в llm_config.json
СерверЛЛМ --> ПанельНастройки : {status: "success",\ncurrent_model: "qwen"}
ПанельНастройки -> Админ : Отобразить новую\nактивную модель

@enduml
