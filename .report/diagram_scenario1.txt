title Сценарий 1: Автоматическая контекстная реакция ассистента

actor "Игрок" as Игрок
participant "Мод Minecraft" as Мод
participant "Сервер FastAPI\n(advice.py)" as Сервер
participant "Буфер событий\n(logs_db)" as Буфер
participant "LLM-клиент\n(GroqClient)" as Клиент
participant "Groq API /\nOllama" as LLM
participant "Резервный\nгенератор" as Резерв
participant "Веб-панель\n(браузер)" as Панель

== Нормальный поток ==

Игрок -> Мод : Игровые действия\n(перемещение, бой, ...)
Мод -> Сервер : POST /api/logs/\n{event_type, player_health, ...}
Сервер -> Буфер : Добавить событие\n(LogEntry)
Буфер --> Сервер : OK

Мод -> Сервер : GET /api/rp/\n(периодический опрос)
Сервер -> Буфер : Получить последние 5 событий
Буфер --> Сервер : [LogEntry × 5]

Сервер -> Сервер : Проверить наличие\nнеобработанных\nкритических событий

alt Критическое событие (гибель персонажа)
    Сервер -> Сервер : Пометить событие\nкак обработанное\nis_critical = True\n(обход ограничителя)
else Обычное событие
    Сервер -> Сервер : Проверить ограничитель\nчастоты (rate limit)\n_should_send_response()
    note right : Если с последней реплики\nпрошло < 20 с\nи ситуация не изменилась —\nвернуть кэш
end

Сервер -> Клиент : generate_tip_async(\n  recent_logs)
Клиент -> Клиент : Сформировать промпт\nиз шаблона + контекст

Клиент -> LLM : POST completions\n(модель, промпт,\nmax_tokens, temperature)
LLM --> Клиент : Текст реплики
Клиент -> Клиент : Удалить блоки\n<think>...</think>\n_strip_thinking()
Клиент --> Сервер : Текст реплики

Сервер -> Сервер : Определить уровень угрозы\n_determine_severity_level()\n(INFO / WARNING / CRITICAL)
Сервер -> Сервер : Обновить кэш\n_last_rp_response

Сервер -> Панель : WebSocket /api/rp/ws\n{response, level, source}
Сервер --> Мод : GroqAdvice\n{response, level,\nconfidence, source: "groq"}
Мод -> Игрок : Отобразить реплику\n(оверлей / чат)

== Альтернативный поток: LLM недоступен ==

Сервер -> Клиент : generate_tip_async(...)
Клиент --> Сервер : None (ошибка / нет ключа)

Сервер -> Резерв : _get_fallback_rp_response(\n  last_log)
Резерв -> Резерв : Приоритетный перебор\nтипов событий:\ndeath → low_health\n→ hunger_low\n→ near_hostile\n→ night → ...
Резерв --> Сервер : {response, source: "fallback"}

Сервер --> Мод : GroqAdvice\n{source: "fallback"}
Мод -> Игрок : Отобразить реплику

@enduml
